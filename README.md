# Mono

Личный клиент Яндекс Музыки для Windows: чёрно-белый интерфейс в стиле Spotify со стеклянными кнопками.

- Вход по своему токену Яндекса (нужна подписка Плюс)
- Моя волна с настройками настроения, характера и языка
- Новинки и чарт обновляются сами
- Мне нравится, плейлисты, поиск
- Плеер: очередь, перемешивание, повтор, громкость

Только для личного использования, не распространять.

## Сборка
Каждый пуш в `main` собирает `.exe` через GitHub Actions — готовый архив лежит в Releases → `latest`.
